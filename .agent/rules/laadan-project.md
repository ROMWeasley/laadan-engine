# Laadan Engine project guidance

For repository-wide engineering and safety rules, follow the root [`AGENTS.md`](../../AGENTS.md). Keep this file limited to Antigravity-specific discovery so the project guidance has one canonical source.

Before proposing or making code changes, read the relevant source and [`docs/architecture.md`](../../docs/architecture.md). The architecture document is a proposal, not evidence that a feature or security property is implemented.

For implementation, preserve existing behavior, make focused changes, and explain assumptions and risks. Do not run commands or tools that execute code unless the user explicitly approves the exact command first.
